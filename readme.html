CrewHub

облік робочого часу за робочим Wi-Fi

Прийшов на точку, телефон у робочому Wi-Fi — зміна йде. Вийшов з мережі — сервер це бачить і ставить зміну на паузу. Усе працює на вашому комп'ютері в мережі точки: без хмар, підписок і інтернету.

Присутність за Wi-Fi

Сервер знає мережі кожної точки й бачить IP телефона. Підробити не вийде: IP визначає сервер.

Зміна сама

Застосунок починає зміну, коли людина приходить у робочий час, і ставить паузу, коли виходить.

Зарплата

Ставки, нічні й вихідні множники, оплачувані перерви, дей-оффи, бонуси й штрафи, CSV для Excel.

Надійно

Дані окремо від програми, щоденні копії, самовідновлення бази, журнал кожної правки.

Запуск за 3 хвилини

  1. Поставте Python 3.10+ (у Windows позначте «Add Python to PATH»).
  2. Відкрийте папку test_app і запустіть start.bat (Windows) або ./start.sh (Linux, macOS).
  3. Відкрийте адресу з консолі (наприклад http://192.168.1.23:5000) на телефоні в тому ж Wi-Fi.
  4. Увійдіть: 050 000 00 01 / admin123. Система одразу попросить задати свій пароль.
  5. «Правила» → години й оплата; «Точки і Wi-Fi» → назва точки; «Працівники» → люди; QR з «Точки і Wi-Fi» — працівникам.

Де лежать дані

Окремо від програми, у папці CrewHub-data в домашній папці користувача (у Windows — C:\Users\<ім'я>\CrewHub-data). Нову версію програми можна розпакувати поверх старої чи будь-куди — люди, зміни, правила й точки лишаться. Правила й точки ще й лежать текстом у settings.ini: його можна правити Блокнотом.

CrewHub-data/
├── crewhub.db       база
├── settings.ini     правила, точки, Wi-Fi, порт
├── people/          особова папка кожного працівника
├── backups/         щоденні копії (30), ручні, видалені
└── logs/            журнал сервера

Найчастіші питання

Чи можна відмітитися з дому?

Ні. Зміна рахується лише з IP робочої мережі точки, а IP визначає сервер. Закрити зміну з дому можна, але кінцем стане останній пінг з точки.

Телефон спав у кишені — зміна стала на паузу?

Ні, якщо стоїть застосунок: сервер чекає до 20 хв, а вихід з Wi-Fi застосунок повідомляє сам з точним часом.

Оновив програму — правила скинулись?

Ні: дані й settings.ini лежать у папці даних окремо від програми.

Забули пароль адміна?

На самому сервері: python recover_admin.py.

Чи потрібен інтернет?

Ні. Сервер і телефони працюють у локальній мережі, іконки й шрифти вбудовані.
