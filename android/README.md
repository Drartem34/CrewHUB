# CrewHub для Android

Легкий застосунок (~300 КБ разом зі сканером QR; в оригінальному описі — ~30 КБ, без нього): при першому запуску питає адресу сервера CrewHub (наприклад `192.168.1.23:5000`)
і відкриває сайт сервера у вбудованому браузері. Перевірку Wi-Fi робить сервер за IP телефона,
тому застосунку не потрібні дозволи на геолокацію чи Wi-Fi.

Можливості: збереження входу, завантаження фото профілю, завантаження табелів CSV, дзвінки й Telegram
з картки колеги, кнопка «Назад», зміна адреси сервера зі сторінки входу (`crewhub://settings`).

## Збірка

```bash
sudo apt install aapt apksigner zipalign dalvik-exchange openjdk-17-jdk
ANDROID_JAR=шлях/до/android.jar ./build.sh   # API 34; → build/CrewHub.apk (див. коментар у build.sh)
```

В оригінальному описі (тоді збірка йшла під API 23):

```bash
sudo apt install android-sdk-platform-23 aapt apksigner zipalign dalvik-exchange openjdk-17-jdk
./build.sh            # → build/CrewHub.apk
```

`crewhub.keystore` (пароль `crewhub123`) — тестовий ключ підпису. Оновлення ставляться поверх
встановленого застосунку лише з тим самим ключем. Для публікації в Google Play створіть власний ключ.
(Цей ключ і пароль були опубліковані разом із кодом — тепер ключ свій, див. нижче.)

Ключ підпису (`crewhub.keystore`) і пароль до нього (`keystore.pass`) `build.sh` створює сам при першій збірці.
Це секрет: їх немає в репозиторії, не пересилайте їх і зробіть резервну копію. Оновлення ставляться поверх
встановленого застосунку лише з тим самим ключем. Можна вказати свій: `CREWHUB_KEYSTORE=шлях CREWHUB_KS_PASS=пароль ./build.sh`.

Старий тестовий ключ (пароль `crewhub123`) був опублікований разом із кодом, тому його замінено. Застосунок,
підписаний старим ключем, оновити поверх не вийде: видаліть його з телефона один раз і встановіть новий.

QR-сканер використовує libs/zxing-core-3.5.3.jar (ZXing, Apache 2.0); build.sh підключає всі jar з libs/ сам.

Повний опис застосунку (що вміє, дозволи, що шле серверу, батарея) — у [docs/07-android.md](../docs/07-android.md).

## Демо без сервера (`demo/`)

`CrewHub_Demo.apk` (пакет `ua.crewhub.demo`, ставиться поруч з робочим): інтерфейс, знятий з `test_app` з тестовими
даними. `build_demo.py` відкриває всі сторінки від імені працівника й адміна і зберігає їх у `assets/www`;
`demo.js` веде переходи між збереженими сторінками, рахує зміну на телефоні і не дає формам нічого зберігати.
Застосунок віддає ці файли за адресою `https://demo.crewhub/` прямо з APK, мережа не потрібна.

```bash
bash demo/build.sh    # → demo/build/CrewHub_Demo.apk (потрібен Flask, як для сервера)
```

Що нового в застосунку: 2.1 — сам знаходить сервер після зміни його IP і входить без пароля; 2.2 — сповіщення
«Телефон відключився від робочого Wi-Fi»; 2.3 — заряд телефона в пінгах і в мить вимкнення. Докладно — docs/07-android.md.
