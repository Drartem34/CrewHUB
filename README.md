# CrewHub

Облік змін, табелів і зарплати для невеликої компанії. Присутність на роботі перевіряється не GPS,
а робочим Wi-Fi: телефон працівника в мережі точки — зміна йде, вийшов з мережі — пауза.

- **Сервер** (`test_app/`): Python, Flask + SQLite. Запускається одним `python start.py` на звичайному
  комп'ютері в мережі точки. Зміни, перерви, контроль Wi-Fi, графік, дей-оффи й відпустки, бонуси/штрафи,
  зарплата, журнали, бекапи, пристрої в мережі. Інтернет не потрібен.
- **Android** (`android/`): легка обгортка над сайтом сервера (~30 КБ) з фоновою службою, що сама починає
  й закінчує зміну за робочим Wi-Fi. Підключення QR-кодом.
- **Документація** (`docs/`): усе для власника, адміністратора, працівника й розробника.

## Швидкий старт

```bash
cd test_app
pip install -r requirements.txt      # Python 3.10+
python start.py                      # у Windows: двічі клацнути start.bat
```

Відкрийте адресу з консолі (наприклад `http://192.168.1.23:5000`) на телефоні в тому ж Wi-Fi.
Перший вхід: `050 000 00 01` / `admin123` — система одразу попросить задати свій пароль.

Дані лежать окремо від програми, у `~/CrewHub-data` (база, особові папки, копії, журнали, `settings.ini`
з правилами й точками). Нову версію можна розпакувати поверх старої чи будь-куди — нічого не скинеться.

## Тести

```bash
cd test_app
python -m unittest test_crewhub test_hardening test_features
```

~130 тестів: логіка змін і зарплати, тест на кожну закриту дірку, фаз-тест (сміття в кожну форму не дає
помилки 500), папка даних і `settings.ini`, пристрої в мережі, сторінки без зовнішніх ресурсів.
