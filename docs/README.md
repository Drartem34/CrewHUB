# Документація CrewHub

CrewHub — облік змін, табелів і зарплати для невеликої компанії з однією чи кількома точками.
Присутність на роботі перевіряється за робочим Wi-Fi. Телефон працівника в мережі точки — зміна йде,
вийшов з мережі — пауза. GPS не потрібен.

Система складається з двох частин:

- **сервер** (`test_app/`) — програма на Python, яка працює на звичайному комп'ютері в офісі чи на точці.
  Сайт сервера відкривається з будь-якого телефона чи ПК у тій самій мережі;
- **Android-застосунок** (`android/`) — легка обгортка над сайтом. Фонова служба в ньому сама починає
  й закінчує зміну за робочим Wi-Fi.

## Коротко про головне

- **Дані окремо від програми.** База, особові папки, копії й журнали лежать у папці даних
  `~/CrewHub-data` (у Windows — `C:\Users\<ім'я>\CrewHub-data`). Нову версію програми можна
  розпакувати будь-куди: люди, зміни, правила й точки не зникнуть. Див. [дані](06-data-and-backups.md).
- **Правила й точки — ще й текстовим файлом** `settings.ini` у папці даних. Його можна правити Блокнотом.
  Див. [правила](04-settings.md#файл-settingsini).
- **Інтернет не потрібен.** Сервер і телефони працюють у локальній мережі. Іконки, шрифти й скрипти
  вбудовані: без інтернету інтерфейс виглядає так само.
- **Перший вхід:** `050 000 00 01` / `admin123`. Система одразу попросить задати свій пароль.
