# 13. Підтвердження номера через WhatsApp (версія 17.11)

Коли людина реєструється сама, сервер надсилає їй у WhatsApp шестизначний код. Вона вводить його на сторінці
реєстрації, і в заявці («Працівники» → «Нові реєстрації») та в картці працівника видно **«✓ номер підтверджено»**.
Так ви бачите, що номер справжній і належить саме цій людині. Заявку, як і раніше, підтверджує адміністратор
або модератор, а без коду — теж можна (у заявці буде «номер не підтверджено»).

Типово вимкнено. Працює через офіційний **WhatsApp Cloud API** від Meta, тому потрібні:

- **інтернет на сервері** — вихідні запити на `graph.facebook.com` (HTTPS);
- **акаунт WhatsApp Business у Meta** з номером, з якого йдуть повідомлення (див. нижче);
- **схвалений шаблон повідомлення** з кодом (категорія «Authentication»).

Meta бере плату за кожне повідомлення з кодом (тариф «Authentication» для країни отримувача) — актуальні ціни в
кабінеті WhatsApp Manager.

## Налаштування в Meta (один раз)

1. На <https://developers.facebook.com> → «Мої застосунки» → «Створити застосунок» → тип **«Бізнес»** → додайте
   продукт **WhatsApp**.
2. WhatsApp → «Налаштування API» (API Setup). Там є тестовий номер і його **Phone number ID** — для перевірки.
   Тестовий номер надсилає лише на кілька номерів, доданих у список «Кому» (To). Для роботи додайте свій номер
   компанії (на ньому не має бути звичайного WhatsApp-застосунку в той самий час) і підтвердьте його кодом із SMS
   чи дзвінка — у нього буде свій Phone number ID.
3. **Постійний токен.** Business Settings (business.facebook.com) → «Користувачі» → «Системні користувачі» → додати
   (роль адміністратора) → «Призначити активи»: ваш застосунок і акаунт WhatsApp → «Створити токен» з дозволами
   `whatsapp_business_messaging` і `whatsapp_business_management`, термін — «Ніколи». Скопіюйте токен одразу: вдруге
   його не покажуть. (Тимчасовий токен зі сторінки API Setup діє лише 24 год — для перевірки.)
4. **Шаблон з кодом.** WhatsApp Manager → «Шаблони повідомлень» → «Створити» → категорія **«Authentication»**
   (Автентифікація) → назва `crewhub_code` → мова **українська** (`uk`) → доставка коду «Скопіювати код» → надіслати
   на перевірку. Зазвичай схвалюють швидко.
5. У WhatsApp Manager додайте спосіб оплати.

## Налаштування в CrewHub

«Правила» → «Дисципліна і доступ» → блок WhatsApp:

| Поле | Що вписати |
|---|---|
| Підтверджувати номер через WhatsApp | галочка |
| Phone number ID (Meta) | з кроку 2 |
| Токен доступу | з кроку 3. Після збереження показується лише «•••• 1234»; щоб замінити — вставте новий, «Стерти токен» — прибрати |
| Назва шаблону з кодом | `crewhub_code` (або ваша назва з кроку 4) |
| Мова шаблону | `uk` (як у шаблоні) |

«Зберегти правила» → **«Надіслати тестовий код мені»**: код прийде на номер вашого акаунта адміністратора. Не
прийшов — під кнопкою буде причина (помилка від WhatsApp або «немає зв'язку з WhatsApp»).

Токен — секрет: він не потрапляє ні в `settings.ini`, ні в «Журнал редагувань» (там лише «токен змінено»), а лежить
у базі. Можна не вписувати його в «Правилах», а задати змінною середовища `CREWHUB_WA_TOKEN` — вона важливіша.
Версію Graph API, якщо Meta колись вимкне типову (`v23.0`), задає змінна `CREWHUB_WA_API`, напр. `v24.0`.

## Як це бачить людина

1. Реєстрація → ім'я, номер, пароль → «Зареєструватися».
2. Сторінка «Підтвердіть номер»: код у WhatsApp на цей номер → ввести → «Підтвердити».
3. «Заявку надіслано ✓ номер підтверджено в WhatsApp».

Код діє 10 хв, на нього 5 спроб; «Надіслати код ще раз» — не частіше раз на хвилину і не більше 5 разів на годину.
Якщо WhatsApp недоступний (сервер без інтернету, помилка налаштувань), людина бачить «Код у WhatsApp не надіслано: …»
— але заявка все одно йде адміністратору, як без підтвердження.
