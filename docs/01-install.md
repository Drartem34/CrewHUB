# Встановлення, запуск і оновлення

## Що потрібно

- Комп'ютер, який стоїть у мережі точки (або в мережі, до якої підключаються телефони). Підходить
  будь-який: Windows 10/11, Linux, macOS, навіть Raspberry Pi. Для 100+ людей вистачає 1 ГБ пам'яті.
- Python 3.10 або новіший ([python.org](https://www.python.org/downloads/); у Windows під час встановлення
  позначте «Add Python to PATH»).
- Інтернет потрібен лише один раз — щоб поставити бібліотеки (`flask`, `waitress`, `psutil`, `rich`).

Порада: закріпіть за сервером постійну адресу в мережі (на роутері: «DHCP-резервація» / «статичний IP»).
Тоді адреса, яку знають телефони, не зміниться після перезавантаження роутера.

## Перший запуск

**Windows:** розпакуйте архів, відкрийте папку `test_app` і двічі клацніть `start.bat`.

**Linux / macOS:**

```bash
cd test_app
./start.sh          # або: pip install -r requirements.txt && python3 start.py
```

`start.bat` / `start.sh` самі ставлять бібліотеки (лише коли їх немає або змінився `requirements.txt`)
і перезапускають сервер, якщо він упав.

У вікні з'явиться список перевірок і адреса, наприклад:

```
 ✔ Папка даних  /home/olena/CrewHub-data
 ✔ База SQLite (нова, тестові дані)
 ✔ Правила й точки (settings.ini)  /home/olena/CrewHub-data/settings.ini
 ✔ Контроль Wi-Fi (фон)
 ...
 Сайт http://192.168.1.23:5000
```

Відкрийте цю адресу на телефоні чи ПК у тій самій Wi-Fi мережі й увійдіть:
**`050 000 00 01` / `admin123`**. Система одразу попросить задати свій пароль.

Підмережа Wi-Fi цього комп'ютера (наприклад `192.168.1.0/24`) при першому запуску стає робочою мережею
«Тестової точки». Перейменуйте точку й додайте інші в «Точки і Wi-Fi».

## Що далі (5 хвилин)

1. **«Правила»** — назва компанії, валюта, робочі години, обід, нічні й вихідні множники.
   Кожне правило пояснено в [04-settings.md](04-settings.md).
2. **«Точки і Wi-Fi»** — назва точки, адреса, Wi-Fi (назва й пароль для QR-коду).
3. **«Працівники» → «+»** — додайте людей: ім'я, телефон (це логін), ставка і тимчасовий пароль
   (від 6 символів), який ви скажете людині. При першому вході вона задасть свій. Або залиште відкритою
   самостійну реєстрацію («Правила» → «Дисципліна і доступ») — тоді кожна нова людина реєструється сама
   й чекає вашого підтвердження.
4. **Роздайте застосунок.** На сторінці входу є посилання «Завантажити застосунок для Android» (якщо на сервері лежить
   `test_app/static/CrewHub.apk`; демо — за адресою `/app/demo`). Підключення — QR-кодом з «Точки і Wi-Fi».
   Див. [07-android.md](07-android.md).

## Автозапуск разом з комп'ютером

**Linux** (systemd):

```bash
cd test_app
./install_service.sh            # служба crewhub: стартує з комп'ютером, перезапускається при збої
./install_service.sh remove     # прибрати службу
journalctl -u crewhub -f        # подивитися, що відбувається
```

**Windows:** покладіть ярлик `start.bat` у папку автозапуску (`Win+R` → `shell:startup`). Комп'ютер не повинен
засинати: «Параметри → Живлення → Сон: ніколи».

### Щоб сервер сам вмикався після відключення світла

Час без світла сервер порахує і зарахує людям сам (див. [05-shifts-and-pay.md](05-shifts-and-pay.md#відключення-світла)),
але лише коли знову запуститься. Тож комп'ютер має вмикатися й запускати сервер без людини:

1. **BIOS/UEFI:** при старті натисніть `Del` (або `F2`) → розділ «Power» / «Живлення» → параметр
   «Restore on AC Power Loss» (буває «AC Back», «After Power Loss») → **Power On**. Тепер комп'ютер вмикається
   сам, щойно з'являється світло. На ноутбуці з акумулятором це не потрібно — він не вимикається.
2. **Вхід у Windows без пароля** (інакше автозапуск чекатиме, поки хтось увійде): `Win+R` → `netplwiz` →
   зніміть «Потрібно вводити ім'я користувача і пароль» → введіть пароль один раз. На Windows 11, якщо галочки
   немає: «Параметри → Облікові записи → Параметри входу» → вимкніть «Для підвищення безпеки дозволяти вхід
   Windows Hello лише…», і галочка з'явиться.
3. **`start.bat` в автозапуску** (див. вище). Сервер сам перезапускається, якщо впаде.
4. **Роутер** вмикається сам — нічого робити не треба. Якщо є ДБЖ, ставте на нього і роутер, і сервер разом.

Перевірка: вимкніть подовжувач, з якого живляться комп'ютер і роутер, на 5 хвилин і ввімкніть. Через
2–3 хвилини сервер має працювати, а в «Підключеннях» з'явиться «Сервер не працював» з точним часом.
На Linux служба `crewhub` (`install_service.sh`) стартує з системою сама; потрібен лише пункт 1.

## Оновлення до нової версії

1. Зупиніть сервер (`Ctrl+C` у вікні або `sudo systemctl stop crewhub`).
2. Розпакуйте нову версію — поверх старої або в нову папку, як зручно.
3. Запустіть `start.bat` / `start.sh` / `sudo systemctl start crewhub`.

Нічого не скидається: база, люди, правила й точки лежать у папці даних, а не в папці програми.
Якщо оновлюєтесь з версії 16 або старішої (тоді база лежала в `test_app/crewhub_test.db`), перший запуск
сам перенесе базу, особові папки й копії в папку даних і напише про це. Стара база лишиться поруч
як `crewhub_test.db.перенесено-<дата>` — це страховка, її можна видалити через тиждень.

Перед оновленням корисно завантажити копію: «Правила» → «Резервні копії» → «Завантажити зараз».

## Доступ з інтернету (необов'язково)

Якщо працівники мають відкривати сайт не лише з Wi-Fi точки (наприклад, переглядати табель вдома):

```bash
pip install pinggy
```

Після перезапуску сервер сам відкриє тунель і покаже адресу «Глобальна мережа». Через тунель сервер бачить
справжній IP телефона, тож відмітитися на зміні з дому однаково не вийде.

## Змінні середовища

Звичайному користувачу вони не потрібні. Задаються перед запуском (`set ИМ'Я=значення` у Windows,
`ИМ'Я=значення ./start.sh` у Linux) або в службі systemd (`Environment=`).

| Змінна | Що робить | Типово |
|---|---|---|
| `CREWHUB_DATA` | папка даних | `~/CrewHub-data` |
| `CREWHUB_PORT` | порт сайту (важливіший за `port` у settings.ini) | `5000` |
| `CREWHUB_TZ` | часовий пояс, напр. `Europe/Kyiv` | системний; на сервері з UTC — `Europe/Kyiv` |
| `CREWHUB_DEMO` | `1` — тестові акаунти й історія змін; `users` — лише акаунти | `0` |
| `CREWHUB_DB` | окремий шлях до бази | `<папка даних>/crewhub.db` |
| `CREWHUB_BACKUP_DIR`, `CREWHUB_PEOPLE_DIR` | окремі шляхи до копій і особових папок | у папці даних |
| `CREWHUB_BACKUP_KEEP` | скільки щоденних копій тримати | `30` |
| `CREWHUB_BACKUP_MIRROR` | друга папка для копій (важливіша за налаштування в «Правилах») | — |
| `CREWHUB_LOG_KEEP_DAYS` | скільки днів тримати журнал підключень | `180` |
| `CREWHUB_LAN_NETS` | які мережі сканувати для «Пристрої в мережі», через кому | своя підмережа |
| `CREWHUB_THREADS` | потоки веб-сервера | `48` |
| `CREWHUB_TRUST_PROXY` | `1` — вірити `X-Forwarded-For` від власного проксі на цьому ж комп'ютері | `0` (pinggy вмикає сам) |
| `CREWHUB_SECRET` | ключ сесій (інакше генерується й зберігається в базі) | — |
| `CREWHUB_PLAIN` | `1` — простий текст у консолі замість панелі | — |
| `CREWHUB_HASH_SLOTS` | скільки паролів перевіряти одночасно | `4` |
| `CREWHUB_CSRF` | `0` вимикає захист форм — лише для автотестів | `1` |

## Якщо щось пішло не так

- **«Порт 5000 уже зайнято»** — сервер уже працює (друге вікно, служба). Другий запуск не потрібен.
  Інший порт: `port = 5080` у `settings.ini` або `CREWHUB_PORT=5080`.
- **Телефон не відкриває адресу** — телефон має бути в тій самій Wi-Fi мережі, а брандмауер Windows
  має пропускати Python (при першому запуску Windows питає — дозвольте «Приватні мережі»).
  Сервер підказує інші свої адреси рядком «Не відкривається з телефона? Спробуйте…».
- **Червоний банер «Сервер потребує уваги»** в адмінці — котрийсь фоновий потік падає.
  Подробиці в `<папка даних>/logs/crewhub.log`.
