# 16. Комп'ютер для сервера: покроково, для Windows і Linux

Тут усе з нуля і по кроках: який комп'ютер підійде, що встановити, які налаштування змінити, щоб сервер
працював сам — вмикався разом з комп'ютером, не засинав, переживав відключення світла. Окремо для
**Windows 10/11** і для **Linux** (Fedora, Ubuntu/Mint/Debian, Arch). Наприкінці — роутер, перевірка і що робити,
якщо щось не так.

Коротко, що треба зробити (на будь-якій системі):

1. Поставити **Python** (на Linux він уже є).
2. Розпакувати **CrewHub** і запустити `start.bat` (Windows) чи `./start.sh` (Linux).
3. Дозволити серверу приймати з'єднання (**брандмауер**).
4. Заборонити комп'ютеру **засинати**.
5. Зробити, щоб сервер **сам запускався** з комп'ютером.
6. У **роутері** закріпити за сервером постійну адресу.

---

## Який комп'ютер підійде

- **Будь-який**, що вмикається: старий ПК, ноутбук, міні-ПК. Для 100 людей вистачає 2 ГБ пам'яті й 10 ГБ місця на диску.
- **Ноутбук — найкраще**: акумулятор працює як ДБЖ — коротке відключення світла сервер навіть не помітить.
  Для ПК бажаний ДБЖ (безперебійник), і бажано, щоб на ньому були і ПК, і роутер.
- Стоїть **на точці** і підключений до **того самого роутера**, що й робочий Wi-Fi. Краще кабелем (стабільніше),
  можна й Wi-Fi.
- Працює весь робочий час (краще цілодобово).
- **Правильний час і часовий пояс** (Київ) — від цього залежать години змін і зарплата. Нижче показано, де це перевірити.

## Windows 10 / 11

### Крок 1. Встановити Python

1. Відкрийте **python.org** → **Downloads** → велика жовта кнопка **«Download Python 3.x.x»** (будь-яка версія від 3.10).
2. Запустіть завантажений файл.
3. **Унизу першого вікна поставте галочку «Add python.exe to PATH»** — це найважливіше!
4. Натисніть **«Install Now»**. Наприкінці, якщо буде кнопка **«Disable path length limit»**, — натисніть і її.
5. Перевірка: `Win + R` → впишіть `cmd` → Enter → у чорному вікні впишіть `python --version` → Enter.
   Має показати `Python 3.x.x`.
   - Відкрився Microsoft Store чи пише «Python не знайдено» — галочку на кроці 3 не поставили. Запустіть
     встановлювач ще раз → **Modify** / **Repair**, або видаліть Python і встановіть заново з галочкою.
     Ще варто вимкнути «псевдоніми»: Параметри → Програми → Додаткові параметри програм → **Псевдоніми
     виконання програм** → вимкніть `python.exe` і `python3.exe`.

### Крок 2. Розпакувати CrewHub

1. Архів `CrewHub_v17_…_full.zip`: правою кнопкою → **Властивості** → унизу галочка **«Розблокувати»** (якщо є) → OK.
   Тоді Windows не питатиме дозволу на кожен файл.
2. Правою кнопкою на архіві → **«Видобути все…»** → вкажіть `C:\` → **Видобути**. Вийде папка `C:\CrewHUB`.
   (Можна й інше місце, але краще коротке, без кирилиці: `C:\CrewHUB`.)

Дані CrewHub (люди, зміни, налаштування) лежать окремо: `C:\Users\<ваше ім'я>\CrewHub-data`. Оновлення
програми їх не чіпає (див. [06-data-and-backups.md](06-data-and-backups.md)).

### Крок 3. Перший запуск

1. Відкрийте `C:\CrewHUB\test_app` і двічі клацніть **`start.bat`**.
2. Якщо з'явиться синє вікно **«Windows захистив ваш ПК»** → **«Докладніше»** → **«Виконати все одно»**.
3. Перший запуск ставить бібліотеки — потрібен **інтернет**, 1–3 хвилини. Наступні запуски — без інтернету.
4. З'явиться вікно **«Брандмауер Захисника Windows заблокував деякі функції»** → поставте галочку
   **«Приватні мережі»** → **«Дозволити доступ»**.
5. У вікні сервера вгорі — **«CrewHub 17.x»**, а в рядку **«Сайт»** (чи «Локальна мережа») — адреса, напр. `http://192.168.0.9:5000`.
   Її відкривають телефони. Вікно **не закривайте** — закриєте, і сервер зупиниться (згорнути можна).

### Крок 4. Мережа має бути «Приватна»

Інакше Windows не пустить телефони до сервера, навіть з дозволом брандмауера.

1. **Параметри** (`Win + I`) → **Мережа й Інтернет**.
2. **Wi-Fi** (або **Ethernet**, якщо кабель) → натисніть на свою мережу (**«Властивості»**).
3. **Тип мережевого профілю** → **«Приватна мережа»**.

Брандмауер пропустив вікно на кроці 3 чи натиснули «Скасувати» → **Пуск** → впишіть `cmd` → правою кнопкою
**«Запуск від імені адміністратора»** → вставте й Enter:

```
netsh advfirewall firewall add rule name="CrewHub" dir=in action=allow protocol=TCP localport=5000,443,5443 profile=private
```

### Крок 5. Заборонити сон

1. **Параметри** → **Система** → **Живлення** (і акумулятор) → **Екран і сон**:
   «Переводити пристрій у сплячий режим» — **«Ніколи»** (обидва пункти, якщо ноутбук). Екран вимикатись може —
   це не заважає.
2. **Ноутбук:** **Пуск** → впишіть **«Панель керування»** → **Електроживлення** → ліворуч **«Дія при закритті
   кришки»** → **«Нічого не робити»** (для «Від мережі» і «Від батареї») → **Зберегти зміни**.

### Крок 6. Час і часовий пояс

**Параметри** → **Час і мова** → **Дата й час**: «Автоматично встановлювати час» — **увімкнено**,
часовий пояс — **(UTC+02:00) Київ** (чи автоматично).

### Крок 7. Щоб Windows не перезавантажувалась посеред зміни

**Параметри** → **Windows Update** → **Додаткові параметри** → **Активні години** → вручну, напр. з 7:00 до 23:00.
У цей час Windows сама не перезавантажиться для оновлень.

### Крок 8. Сервер запускається сам

1. **Ярлик в автозапуск:** відкрийте `C:\CrewHUB\test_app` → правою кнопкою на `start.bat` → **«Створити ярлик»**.
   Потім `Win + R` → впишіть `shell:startup` → Enter → у папку, що відкрилась, **перетягніть цей ярлик**.
2. **Вхід у Windows без пароля** (інакше після перезавантаження сервер чекатиме, поки хтось увійде):
   `Win + R` → `netplwiz` → зніміть галочку **«Потрібно вводити ім'я користувача й пароль»** → OK → двічі введіть
   пароль. Немає такої галочки (Windows 11) → **Параметри** → **Облікові записи** → **Параметри входу** → вимкніть
   **«Для підвищення безпеки дозволяти вхід Windows Hello лише для облікових записів Microsoft…»** — галочка
   з'явиться.
3. **Вмикатися після відключення світла** — див. «BIOS» нижче (однаково для Windows і Linux).

Перевірка: перезавантажте комп'ютер — без вашої участі має з'явитись вікно сервера.

## Linux (Fedora, Ubuntu / Mint / Debian, Arch)

Команди вводяться в **Терміналі** (Ctrl + Alt + T чи знайти «Термінал» у меню). Після команди — Enter.
Коли спитає пароль — це пароль вашого користувача (символи не показуються, так і має бути).

### Крок 1. Встановити пакети

**Fedora:**
```bash
sudo dnf install -y python3 python3-pip unzip iproute
```

**Ubuntu, Linux Mint, Debian:**
```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip unzip iproute2
```

**Arch, Manjaro:**
```bash
sudo pacman -S --needed python python-pip unzip iproute2
```

Перевірка: `python3 --version` — має бути 3.10 чи новіше.

### Крок 2. Розпакувати CrewHub

```bash
mkdir -p ~/crewhub
cd ~/crewhub
unzip ~/Downloads/CrewHub_v17_18_full.zip       # чи ~/Завантаження/… — де лежить архів
cd CrewHUB/test_app
chmod +x start.sh install_service.sh
```

Дані CrewHub (люди, зміни, налаштування) лежать окремо: `~/CrewHub-data`. Оновлення програми їх не чіпає.

### Крок 3. Перший запуск

```bash
./start.sh
```

- Перший раз ставить бібліотеки у свою папку `.venv` — потрібен **інтернет**, 1–3 хвилини.
- Сам відкриває в брандмауері порти **5000** і **5443** (firewalld на Fedora, ufw на Ubuntu) — спитає пароль.
- У вікні вгорі — **«CrewHub 17.x»**, у рядку **«Сайт»** — адреса для телефонів, напр. `http://192.168.0.9:5000`.
- Зупинити — **Ctrl + C**.

Бібліотеки не поставились (немає інтернету, особливий Python) — поставте вручну й запустіть знову:
```bash
.venv/bin/python -m pip install -r requirements.txt
```

Брандмауер вручну (якщо телефони не відкривають сайт):
- Fedora (firewalld): `sudo firewall-cmd --permanent --add-port=5000/tcp --add-port=5443/tcp && sudo firewall-cmd --reload`
- Ubuntu (ufw): `sudo ufw allow 5000/tcp && sudo ufw allow 5443/tcp`
- Arch: зазвичай брандмауера немає — нічого робити не треба.

### Крок 4. Сервер як служба (сам стартує з комп'ютером, навіть без входу в систему)

Коли перевірили, що `./start.sh` працює, зупиніть його (Ctrl + C) і:

```bash
./install_service.sh
```

Тепер сервер працює у фоні: стартує разом з комп'ютером і сам перезапускається, якщо впаде. Вікна з таблицею
вже не буде — усе видно на сайті. Корисні команди:

| Що | Команда |
|---|---|
| Чи працює | `systemctl status crewhub` |
| Що відбувається (журнал) | `journalctl -u crewhub -f` (вийти — Ctrl + C) |
| Перезапустити (напр. після оновлення) | `sudo systemctl restart crewhub` |
| Зупинити / запустити | `sudo systemctl stop crewhub` / `sudo systemctl start crewhub` |
| Прибрати службу | `./install_service.sh remove` |

Адресу сервера покаже `hostname -I` (перша адреса) або журнал (рядок «Сервер працює»).

### Крок 5. Заборонити сон

Найпростіше й надійно — одною командою заборонити системі засинати взагалі:
```bash
sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target
```
(Повернути: те саме з `unmask`.)

**Ноутбук — щоб не засинав при закритій кришці:**
```bash
sudo nano /etc/systemd/logind.conf
```
Знайдіть рядки (приберіть `#` на початку) і зробіть так:
```
HandleLidSwitch=ignore
HandleLidSwitchExternalPower=ignore
HandleLidSwitchDocked=ignore
```
Зберегти — **Ctrl + O**, Enter; вийти — **Ctrl + X**. Потім `sudo systemctl restart systemd-logind`.

### Крок 6. Час і часовий пояс

```bash
timedatectl
```
Має бути `Time zone: Europe/Kyiv` і `System clock synchronized: yes`. Інакше:
```bash
sudo timedatectl set-timezone Europe/Kyiv
sudo timedatectl set-ntp true
```

### Крок 7. Оновлення системи

Оновлюйте систему коли зручно, **не посеред зміни**: після оновлення ядра комп'ютер треба перезавантажити, а
служба `crewhub` після перезавантаження запуститься сама. Автоматичних перезавантажень Fedora й Ubuntu за
замовчуванням не роблять.

## BIOS: вмикатися після відключення світла (і Windows, і Linux)

Щоб після відключення світла комп'ютер увімкнувся сам (а з ним — сервер):

1. Вимкніть комп'ютер. Увімкніть і одразу кілька разів натискайте **Del** (на деяких — **F2**, **F10** чи **Esc**).
2. Знайдіть розділ **Power** / **Power Management** / **Живлення** (буває в **Advanced** → **APM**).
3. Параметр **«Restore on AC Power Loss»** (може зватися **«AC Back»**, **«After Power Loss»**, **«Power On After
   Power Fail»**) → **Power On**.
4. **Save & Exit** (зазвичай **F10**) → Yes.

Ноутбуку це не потрібно: від акумулятора він не вимикається.

Перевірка: вимкніть подовжувач, з якого живляться комп'ютер і роутер, на хвилину і ввімкніть. За 2–3 хвилини
сервер має працювати сам, а в «Підключеннях» з'явиться «Сервер не працював» з точним часом.

## Роутер

### Постійна адреса для сервера (обов'язково)

Інакше після перезавантаження роутер може дати серверу іншу адресу — і телефони його не знайдуть.

1. Дізнайтесь **MAC** сервера (фізичну адресу мережевої карти):
   - Windows: `Win + R` → `cmd` → `ipconfig /all` → у вашого адаптера рядок **«Фізична адреса»** (напр. `A4-2B-B0-11-22-33`).
   - Linux: `ip link` → рядок `link/ether` у вашого адаптера (`wlp…` — Wi-Fi, `enp…` / `eth…` — кабель).
2. Зайдіть у роутер: у браузері відкрийте адресу роутера (часто `192.168.0.1` або `192.168.1.1`, написано на
   наклейці знизу роутера) → логін і пароль (теж на наклейці, якщо не міняли).
3. Знайдіть **DHCP** → **«Резервування адрес»** / **«Address Reservation»** / **«Static Lease»** / **«Прив'язка IP до MAC»**.
4. Додайте: MAC сервера → адреса, яку він має зараз (з рядка «Сайт» у вікні сервера) → Зберегти.

### Ще три речі в роутері

- **Телефони мають бути в тій самій мережі, що й сервер.** Не в **гостьовій** Wi-Fi: гостьова мережа зазвичай
  ізолює пристрої, і телефон сервер не побачить. Так само вимкніть **«Ізоляцію клієнтів» / «AP Isolation»** для
  робочої мережі, якщо вона ввімкнена.
- **Підсилювач Wi-Fi чи другий роутер** переведіть у режим **«Точка доступу» / «Міст» (Access Point / Bridge)**.
  Інакше сервер бачить замість телефонів сам підсилювач (див. [08-security.md](08-security.md)).
- **Шифрування (HTTPS) не відкривається на телефонах, хоча в «Правилах» «Працює»** — у роутері вимкніть
  **«DNS Rebinding Protection»** (є не в усіх роутерах). Див. [15-https-duckdns.md](15-https-duckdns.md).

## Перевірка: усе працює

1. Вікно сервера (чи `systemctl status crewhub` на Linux) — працює, вгорі **«CrewHub 17.x»**.
2. На **телефоні в робочому Wi-Fi** відкрийте адресу з рядка **«Сайт»** (напр. `http://192.168.0.9:5000`) —
   відкривається сторінка входу.
3. Вхід: **`050 000 00 01`** / **`admin123`** → система одразу попросить свій пароль.
4. Далі — перші налаштування: [01-install.md](01-install.md#що-далі-5-хвилин) (точка, Wi-Fi, люди), шифрування —
   [15-https-duckdns.md](15-https-duckdns.md), підтвердження номерів у Telegram — [14-telegram.md](14-telegram.md).
5. Перезавантажте комп'ютер — сервер піднімається сам.
6. Резервні копії база робить сама щодня (`CrewHub-data/backups`). Для певності раз на тиждень копіюйте папку
   `CrewHub-data` на флешку чи в Google Диск ([06-data-and-backups.md](06-data-and-backups.md)).

## Якщо щось не так

| Що бачите | Що зробити |
|---|---|
| Телефон не відкриває сайт (довго крутиться) | Брандмауер (Windows крок 4, Linux крок 3); мережа Windows не «Приватна»; телефон у гостьовій Wi-Fi чи в мобільному інтернеті; на телефоні введено не ту адресу |
| «Не в робочій мережі» на телефоні | Мережа, де стоїть сервер, не додана в точку: в адмінці вгорі червона картка «Нова мережа» → «Створити точку» (чи «Додати мережу» до існуючої) |
| Сервер зникає вночі / після обіду | Комп'ютер засинає — крок «Заборонити сон» |
| Після відключення світла сервер не піднявся | BIOS «Restore on AC Power Loss» → Power On; Windows: вхід без пароля і ярлик в автозапуску; Linux: `./install_service.sh` |
| Години змін з'їхали на годину-дві | Неправильний часовий пояс — крок «Час і часовий пояс» |
| `start.bat` одразу закривається | Python не встановлено чи без галочки «Add to PATH» — Windows крок 1 |
| `./start.sh: Permission denied` | `chmod +x start.sh install_service.sh` |
| Після перезавантаження роутера телефони не бачать сервер | Не закріплена адреса — розділ «Роутер» |
| Перенести сервер на інший комп'ютер | Підготуйте новий за цією інструкцією і перенесіть папку `CrewHub-data` — [06-data-and-backups.md](06-data-and-backups.md#перенести-сервер-на-інший-компютер) |
